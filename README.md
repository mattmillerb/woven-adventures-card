## 🎲 Overview

**Woven Adventures** is an interactive hybrid tabletop game and digital experience engineered by **[Spraycan Creative](https://spraycancreative.com)**. It bridges physical tabletop gaming with responsive digital narrative mechanics, featuring wrapped 2D game box unboxing, 10-slot card back discovery, multi-choice quadrant slicing, and branching narrative resolution.

---

## ✨ Features & Architecture

- **Interactive 2D Box Unboxing:** Animated lid removal and card extraction transitions.
- **Card Discovery Mechanics:** 10 numbered card slots with directional quadrant slice discovery.
- **Branching Narrative Engine:** Dynamic front-of-card storyline with contextual blanks filled in real-time.
- **Responsive Layout Architecture:** Tight responsive fit engineered for desktop, tablet, and mobile browsers.
- **Production Isolation:** Isolated WordPress shortcode (`[woven_adventures]`) and custom template router.
